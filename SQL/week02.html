제약조건·데이터 입력

블록 1/2

제약조건과 기본 키

1.제약조건·PK
2.INSERT 입력

테이블에 '규칙'을 거는 법(제약조건)과, 잘못 만든 테이블을 고치는 법(ALTER)을 배운다.

제약조건이란

컬럼에 들어올 수 있는 값을 제한하는 규칙이다. 잘못된 데이터가 처음부터 못 들어오게 막아 데이터 품질(무결성)을 지킨다. 게임에서 같은 user_id가 두 명이면 대형 사고이므로 규칙이 필수다.

기본 키 (PRIMARY KEY)

테이블에서 각 행을 유일하게 식별하는 컬럼이다. 유저 테이블의 user_id가 그 예다.

  • 중복 값을 넣을 수 없다 (같은 user_id 두 번 → 에러)
  • 자동으로 NOT NULL이 적용된다 (비워둘 수 없음)
  • 테이블당 단 하나만 존재한다
MySQL · query.sql
CREATE TABLE user (
    user_id     INT          NOT NULL,
    server_id   INT          NOT NULL,
    login_id    VARCHAR(20)  NOT NULL,
    nickname    VARCHAR(20)  NOT NULL,
    level       INT          NOT NULL,
    age         INT          NULL,        -- 나이는 선택 입력
    vip_grade   VARCHAR(2)   NULL,        -- VIP 등급도 선택
    join_date   DATE         NOT NULL,
    PRIMARY KEY (user_id)                 -- user_id를 기본 키로 지정
);

이미 만든 테이블 고치기 (ALTER)

테이블을 다시 만들지 않고 구조만 바꾼다.

MySQL · query.sql
-- 컬럼 추가
ALTER TABLE user ADD last_login DATE NULL;

-- 기본 키 추가 / 삭제
ALTER TABLE user ADD PRIMARY KEY (user_id);
ALTER TABLE user DROP PRIMARY KEY;
💡 식별자(이름) 규칙

테이블·컬럼 이름은 최대 64자, 영문·숫자·한글·_·$ 사용 가능. 단 예약어(SELECT, ORDER 등)는 이름으로 못 쓴다. 그래서 character 테이블을 character_tb로 지은 것이다.

블록 2/2

데이터 입력 — INSERT

1.제약조건·PK
2.INSERT 입력

빈 테이블에 데이터를 채운다. 조회(SELECT)를 연습하려면 데이터가 있어야 하므로, 이번 주에 게임 DB의 모든 데이터를 직접 입력한다.

한 줄 입력 — 단일 INSERT

MySQL · query.sql
INSERT INTO job (job_id, job_name, job_type)
VALUES (10, '워리어', '근접');
  • 컬럼 목록과 값의 개수·순서·타입이 일치해야 한다
  • 문자열은 작은따옴표, 숫자는 그대로
  • NOT NULL 컬럼은 반드시 값을 넣는다

여러 줄 한 번에 — 다중 INSERT

VALUES 뒤에 괄호를 콤마로 이어 붙이면 한 문장으로 여러 행을 넣는다. 훨씬 효율적이다.

MySQL · query.sql
INSERT INTO job VALUES
(10, '워리어',   '근접'),
(11, '아처',     '원거리'),
(12, '메이지',   '마법'),
(13, '프리스트', '지원'),
(14, '어쌔신',   '근접');
📌 컬럼 목록 생략

모든 컬럼에 순서대로 값을 넣을 땐 컬럼 목록을 생략할 수 있다(위 예시). 단 테이블 정의 순서를 정확히 지켜야 하므로, 초보 때는 컬럼을 명시하는 습관이 안전하다.

💡 NULL 입력하기

값이 없는 칸은 NULL이라고 직접 쓴다(따옴표 없이). 화살의달인의 나이 자리에 NULL을 넣으면 '나이 미입력' 유저가 된다. 이런 유저들이 나중에 IS NULL, IFNULL 실습의 주인공이 된다.

🎯 게임 DB 데이터 마저 채우기 표준
  1. 위 서버·유저 데이터를 입력한다
  2. 이어서 character_tb, item, payment 데이터도 입력한다 (배포 SQL 파일 제공)
  3. 각 테이블을 SELECT로 조회해 행 수를 확인한다
💬 힌트: 다음 주 SELECT를 미리 써본다. SELECT * FROM 테이블;
모범답안 보기
answer.sql
-- 입력 후 확인
SELECT * FROM game_server;   -- 4행
SELECT * FROM user;          -- 8행
SELECT COUNT(*) FROM user;   -- 8
