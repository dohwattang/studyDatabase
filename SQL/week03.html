기본 조회 SELECT

블록 1/2

데이터 조회의 시작 — SELECT

1.SELECT 기본
2.정렬·중복제거

SQL의 심장인 SELECT를 배운다. 데이터베이스에 "이런 데이터 보여줘"라고 질문하는 명령이다. 게임 운영의 90%는 이 SELECT로 이뤄진다.

가장 기본 — 전체 조회

*(별표)는 '모든 컬럼'을 뜻한다.

MySQL · query.sql
SELECT * FROM user;
user_idserver_idnicknamelevelagevip_grade...
10011검은기사8527VIP...
10021화살의달인72(NULL)(NULL)...
10032불꽃마녀9031VVIP...

원하는 컬럼만 골라서

필요한 컬럼만 나열하면, 그 컬럼만 그 순서대로 나온다. 운영 리포트는 보통 일부 컬럼만 본다.

MySQL · query.sql
SELECT nickname, level FROM user;
nicknamelevel
검은기사85
화살의달인72
불꽃마녀90
치유의손64

별칭 (AS) — 컬럼 이름 바꿔 보기

영문 컬럼명을 보고서용 한글 이름으로 바꿔 출력한다. AS는 생략 가능하다.

MySQL · query.sql
SELECT nickname AS 닉네임,
       level AS 레벨
FROM user;
닉네임레벨
검은기사85
화살의달인72
불꽃마녀90
💡 계산식에도 별칭

별칭은 계산 결과에도 붙는다. SELECT price/1000 AS 천원단위 FROM item; 처럼 아이템 가격을 천원 단위로 환산하면서 이름까지 붙일 수 있다.

🎯 운영 리포트용 유저 목록 뽑기 기초
  1. user 테이블에서 닉네임·레벨·가입일을 조회한다
  2. 컬럼명을 각각 '닉네임', '레벨', '가입일'로 바꿔 출력한다
모범답안 보기
answer.sql
SELECT nickname  AS 닉네임,
       level     AS 레벨,
       join_date AS 가입일
FROM user;
블록 2/2

정렬과 중복 제거

1.SELECT 기본
2.정렬·중복제거

조회 결과를 정렬하고, 중복을 제거한다. 리포트의 가독성을 좌우하는 기술이다.

정렬 — ORDER BY

특정 컬럼 기준으로 줄을 세운다. ASC=오름차순(기본), DESC=내림차순.

MySQL · query.sql
-- 레벨 높은 순으로 (랭킹)
SELECT nickname, level
FROM user
ORDER BY level DESC;
nicknamelevel
백전노장99
불꽃마녀90
검은기사85
그림자칼날78

여러 기준으로 정렬

콤마로 기준을 이으면, 앞 기준이 같을 때 뒤 기준으로 정렬한다. 서버별로 묶고, 그 안에서 레벨 높은 순.

MySQL · query.sql
SELECT server_id, nickname, level
FROM user
ORDER BY server_id ASC, level DESC;
server_idnicknamelevel
1검은기사85
1화살의달인72
1주말전사40
2불꽃마녀90

중복 제거 — DISTINCT

같은 값을 한 번씩만 보여준다. "우리 서버가 어느 지역에 있더라?" 같은 질문에 쓴다.

MySQL · query.sql
SELECT DISTINCT region
FROM game_server;
region
동부
서부
중부
📌 DISTINCT 위치

DISTINCT는 SELECT 바로 뒤, 컬럼 앞에 딱 한 번 쓴다. 여러 컬럼을 쓰면 그 조합이 중복인 행만 제거된다.

상위 N개만 — LIMIT

정렬과 함께 쓰면 'TOP N' 리포트가 된다. 레벨 랭킹 top 3.

MySQL · query.sql
SELECT nickname, level
FROM user
ORDER BY level DESC
LIMIT 3;
nicknamelevel
백전노장99
불꽃마녀90
검은기사85
🎯 레벨 랭킹 TOP 5 만들기 표준
  1. user 테이블에서 닉네임과 레벨을 조회한다
  2. 레벨이 높은 순으로 정렬한다
  3. 상위 5명만 출력한다
💬 힌트: ORDER BY ... DESC 와 LIMIT을 함께 쓴다
모범답안 보기
answer.sql
SELECT nickname AS 닉네임, level AS 레벨
FROM user
ORDER BY level DESC
LIMIT 5;

3주차 치트시트

SELECT * FROM 테이블;전체 컬럼 조회
SELECT 컬럼1, 컬럼2 FROM 테이블;원하는 컬럼만
컬럼 AS 별칭컬럼 이름 바꿔 출력
ORDER BY 컬럼 ASC오름차순 정렬(기본)
ORDER BY 컬럼 DESC내림차순 정렬
ORDER BY A, B DESCA 우선, 그 안에서 B 내림차순
DISTINCT 컬럼중복 제거
LIMIT n상위 n개만
