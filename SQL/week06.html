날짜를 가공하고(가입 후 며칠?), 데이터 타입을 변환한다. 결제·접속 로그 분석의 토대다.

함수기능예

형변환 — CAST / CONVERT

데이터 타입을 강제로 바꾼다. 문자로 저장된 날짜를 날짜형으로, 숫자를 문자로 등.

MySQL · query.sql
SELECT CAST('2024-03-01' AS DATE)   AS 방법1,
       CONVERT('2024-03-01', DATE) AS 방법2;
블록 2/2

NULL 처리와 흐름제어

1.날짜·형변환
2.흐름제어 CASE

조건에 따라 다른 값을 출력한다. NULL을 처리하고, 데이터를 등급/구간으로 분류한다. SQL 안에서 if문을 쓰는 셈이다.

NULL 처리 3형제

함수기능
IFNULL(a, b)a가 NULL이면 b, 아니면 a
NULLIF(a, b)a와 b가 같으면 NULL, 다르면 a
COALESCE(a,b,c..)NULL이 아닌 첫 값
MySQL · query.sql
-- VIP 등급 없는 유저는 '일반'으로 표시
SELECT nickname,
       IFNULL(vip_grade, '일반') AS 등급
FROM user;
nickname등급
검은기사VIP
화살의달인일반
불꽃마녀VVIP
그림자칼날일반
📌 왜 NULL 처리가 중요한가

NULL은 계산·표시에서 사고를 잘 낸다. 리포트에 빈칸이 뜨거나, NULL + 100이 NULL이 되는 식이다. 운영 리포트는 IFNULL로 빈칸을 의미있는 기본값으로 채워주는 게 기본이다.

IF — 한 줄 조건

MySQL · query.sql
-- 레벨 80 이상이면 '고렙', 아니면 '일반'
SELECT nickname, level,
       IF(level >= 80, '고렙', '일반') AS 구분
FROM user
LIMIT 4;

CASE — 여러 갈래 분류

if-elseif-else다. 유저를 레벨 구간으로 분류해보자.

MySQL · query.sql
SELECT nickname, level,
  CASE WHEN level >= 90 THEN '만렙급'
       WHEN level >= 70 THEN '고렙'
       WHEN level >= 40 THEN '중렙'
       ELSE '초보'
  END AS 등급
FROM user
ORDER BY level DESC;
nicknamelevel등급
백전노장99만렙급
불꽃마녀90만렙급
검은기사85고렙
치유의손64중렙
초보모험가15초보
🎯 결제 등급 라벨링 도전

아이템 가격으로 등급을 매겨라.

  1. price가 40000 이상 → '프리미엄'
  2. 20000 이상 → '일반'
  3. 그 외 → '저가'
  4. item_name, price, 등급 컬럼을 가격 높은 순으로
💬 힌트: CASE WHEN ... THEN ... 을 가격 높은 구간부터 차례로
모범답안 보기
answer.sql
SELECT item_name, price,
  CASE WHEN price >= 40000 THEN '프리미엄'
       WHEN price >= 20000 THEN '일반'
       ELSE '저가'
  END AS 등급
FROM item
ORDER BY price DESC;
