학습 범위 · 1~6주차

테이블·데이터·NULL 이해, SELECT·AS·DISTINCT·ORDER BY·LIMIT, WHERE 비교·LIKE·IN·BETWEEN·AND/OR/NOT, 숫자·문자·날짜 함수, CAST·IFNULL·IF·CASE를 조합한다. 모든 문제는 한 테이블의 SELECT 한 문장으로 해결한다. GROUP BY·집계·JOIN·서브쿼리·윈도 함수는 사용하지 않는다.

초기 실습 데이터 기준이며, 날짜 계산 기준일은 2024-04-30으로 고정한다. 기존 데이터를 변경하지 않고 풀이한다. 아래 표는 생략 없는 전체 기대 결과다. 숫자 뒤의 0 표시는 도구에 따라 다를 수 있다.

진행 방법

각 문제를 먼저 읽고 예상 출력 컬럼·필터 조건·계산 순서·정렬 기준을 정리한 뒤 쿼리를 작성하라. 기대 결과의 행 수와 순서까지 일치시키고, 마지막에 모범답안과 비교하라.

Q1. 이벤트 대상자의 두 갈래 조건 고난도

user에서 ① 1·2번 서버이면서 레벨 70 이상인 유저 또는 ② 나이가 입력되어 있고 30세 이상인 유저를 골라라. 두 갈래 모두 가입일이 2023-03-01 이전이어야 한다. 명패는 '닉네임 [Lv.레벨 / 등급]'이며 NULL 등급은 '일반'이다. 서버ID·명패·가입일을 출력하고, 레벨 내림차순 → 가입일 오름차순 → user_id 오름차순으로 정렬하라.

🎯 기대 결과 · 4행
서버ID명패가입일
4백전노장 [Lv.99 / VVIP]2023-02-01
2불꽃마녀 [Lv.90 / VVIP]2021-03-02
1검은기사 [Lv.85 / VIP]2021-03-05
1화살의달인 [Lv.72 / 일반]2021-04-10
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT server_id AS 서버ID,
       CONCAT(nickname, ' [Lv.', level, ' / ', IFNULL(vip_grade, '일반'), ']') AS 명패,
       join_date AS 가입일
FROM user
WHERE ((server_id IN (1, 2) AND level >= 70)
       OR (age IS NOT NULL AND age >= 30))
  AND join_date < '2023-03-01'
ORDER BY level DESC, join_date, user_id;

OR로 묶은 두 조건 바깥에 공통 가입일 조건을 적용한다.

Q2. NULL을 포함한 일반 유저 선발 고난도

VIP등급이 NULL인 유저 중 레벨 40~80이며, 나이가 NULL이거나 25세 미만인 유저를 선발하라. 닉네임·등급(NULL은 일반)·나이(NULL은 미입력)·레벨을 출력하라. 나이가 입력된 유저를 먼저, 그다음 레벨 내림차순·user_id 오름차순으로 정렬하라.

🎯 기대 결과 · 3행
닉네임등급나이레벨
그림자칼날일반2478
화살의달인일반미입력72
주말전사일반미입력40
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT nickname AS 닉네임, IFNULL(vip_grade, '일반') AS 등급,
       IFNULL(age, '미입력') AS 나이, level AS 레벨
FROM user
WHERE vip_grade IS NULL AND level BETWEEN 40 AND 80
  AND (age IS NULL OR age < 25)
ORDER BY IF(age IS NULL, 1, 0), level DESC, user_id;

NULL 비교와 출력용 대체값을 구분한다. IF로 정렬 우선순위를 만든다.

Q3. 우선순위가 겹치는 운영 등급 고난도

모든 user를 다음 규칙에서 먼저 만족하는 하나로 분류하라: VVIP이면서 레벨 90 이상이면 'S', 그 외 VIP 또는 VVIP이면 'A', 그 외 레벨 70 이상이면서 나이가 입력되어 있으면 'B', 나머지는 'C'. 닉네임·운영등급·레벨·가입월(YYYY-MM)을 출력하고 등급 S→A→B→C, 같은 등급은 레벨 내림차순·user_id 오름차순으로 정렬하라.

🎯 기대 결과 · 8행
닉네임운영등급레벨가입월
백전노장S992023-02
불꽃마녀S902021-03
검은기사A852021-03
치유의손A642022-01
그림자칼날B782022-06
화살의달인C722021-04
주말전사C402024-03
초보모험가C152023-09
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT nickname AS 닉네임,
       CASE WHEN vip_grade = 'VVIP' AND level >= 90 THEN 'S'
            WHEN vip_grade IN ('VIP', 'VVIP') THEN 'A'
            WHEN level >= 70 AND age IS NOT NULL THEN 'B'
            ELSE 'C' END AS 운영등급,
       level AS 레벨, DATE_FORMAT(join_date, '%Y-%m') AS 가입월
FROM user
ORDER BY CASE 운영등급 WHEN 'S' THEN 1 WHEN 'A' THEN 2
         WHEN 'B' THEN 3 ELSE 4 END, level DESC, user_id;

CASE는 먼저 참인 조건에서 끝난다. S→A→B→C는 알파벳순과 다르므로 정렬용 CASE가 필요하다. 화살의달인은 나이가 NULL이므로 C이다.

Q4. 한글 닉네임과 계정 마스킹 고난도

user에서 닉네임이 4글자이고 로그인ID가 8글자 이상인 유저만 골라라. 닉네임·닉네임글자수·공개ID·서버코드를 출력하라. 공개ID는 로그인ID 앞 3글자를 대문자로 바꾼 뒤 '***'를 붙이고, 서버코드는 'S-' 뒤에 서버ID를 2자리로 0 채움한다. 로그인ID 글자수 내림차순·user_id 오름차순으로 정렬하라.

🎯 기대 결과 · 4행
닉네임닉네임글자수공개ID서버코드
검은기사4DAR***S-01
주말전사4CAS***S-01
불꽃마녀4FIR***S-02
백전노장4OLD***S-04
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT nickname AS 닉네임, CHAR_LENGTH(nickname) AS 닉네임글자수,
       CONCAT(UPPER(SUBSTRING(login_id, 1, 3)), '***') AS 공개ID,
       CONCAT('S-', LPAD(server_id, 2, '0')) AS 서버코드
FROM user
WHERE CHAR_LENGTH(nickname) = 4 AND CHAR_LENGTH(login_id) >= 8
ORDER BY CHAR_LENGTH(login_id) DESC, user_id;

한글 글자수는 CHAR_LENGTH로 판단하고, 출력 컬럼에 없는 계산값으로 정렬한다.

Q5. 고정 기준일의 주간 출석 보상 고난도

기준일은 2024-04-30이다. 가입 후 200일 이상이며 서버ID가 1 또는 3인 유저를 골라라. 닉네임·가입일·경과일·완료주수·다음보상까지를 출력하라. 완료주수는 경과일/7의 내림, 다음보상까지는 나머지가 0이면 0, 아니면 7-나머지다. 다음보상까지 오름차순 → 경과일 내림차순 → user_id 순으로 정렬하라.

🎯 기대 결과 · 4행
닉네임가입일경과일완료주수다음보상까지
그림자칼날2022-06-15685971
검은기사2021-03-0511521643
초보모험가2023-09-01242343
화살의달인2021-04-1011161594
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT nickname AS 닉네임, join_date AS 가입일,
       DATEDIFF('2024-04-30', join_date) AS 경과일,
       FLOOR(DATEDIFF('2024-04-30', join_date) / 7.0) AS 완료주수,
       IF(MOD(DATEDIFF('2024-04-30', join_date), 7) = 0, 0,
          7 - MOD(DATEDIFF('2024-04-30', join_date), 7)) AS 다음보상까지
FROM user
WHERE DATEDIFF('2024-04-30', join_date) >= 200 AND server_id IN (1, 3)
ORDER BY 다음보상까지, 경과일 DESC, user_id;

DATEDIFF의 인수 순서와 나머지가 0일 때의 예외 처리를 확인한다.

Q6. 카테고리 할인 뒤 추가 쿠폰 고난도

item에서 무기·코스튬만 조회하라. 무기는 정가의 20%, 코스튬은 10% 할인한 뒤 1,500원 쿠폰을 추가 차감하고 최종 반올림한다. 최종가가 30,000원 이상이면 '프리미엄', 아니면 '일반'이다. 아이템·카테고리·정가·최종가·가격대를 최종가 오름차순·item_id 순으로 출력하라.

아이템카테고리정가최종가가격대
미스릴활무기2490018420일반

MySQL · answer.sql
SELECT item_name AS 아이템, category AS 카테고리, price AS 정가,
       ROUND(price * IF(category = '무기', 0.8, 0.9) - 1500) AS 최종가,
       CASE WHEN ROUND(price * IF(category = '무기', 0.8, 0.9) - 1500) >= 30000
            THEN '프리미엄' ELSE '일반' END AS 가격대
FROM item
WHERE category IN ('무기', '코스튬')
ORDER BY 최종가, item_id;

추가 쿠폰은 할인 계산 이후에 차감한다. 같은 SELECT의 별칭은 다른 출력 수식에서 재사용하지 않는다.

Q7. 예산으로 살 수 있는 묶음 수 고난도

이름에 '포션'이 들어가는 item을 조회하라. 한 상품은 10개 묶음이며 할인 없이 5,000원 예산을 쓴다. 상품명은 'x10'을 ' (10개 묶음)'으로 치환한다. 상품·묶음가격·최대묶음수·총포션수·남는돈을 출력하라. 최대묶음수는 예산/가격의 내림, 총포션수는 최대묶음수×10, 남는돈은 나머지로 계산한다. 남는돈 오름차순·item_id 순으로 정렬하라.

🎯 기대 결과 · 2행
상품묶음가격최대묶음수총포션수남는돈
체력포션 (10개 묶음)900550500
마나포션 (10개 묶음)900550500
모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT REPLACE(item_name, 'x10', ' (10개 묶음)') AS 상품,
       price AS 묶음가격, FLOOR(5000.0 / price) AS 최대묶음수,
       FLOOR(5000.0 / price) * 10 AS 총포션수, MOD(5000, price) AS 남는돈
FROM item
WHERE item_name LIKE '%포션%'
ORDER BY 남는돈, item_id;

묶음 수와 실제 포션 수를 구분한다.

Q8. 최소 결제 충전 단위 고난도

payment에서 2024년 1분기이고 금액이 20,000원 이상인 결제를 골라라. 충전은 10,000원 단위로만 가능하다. 결제ID·결제일(YYYY/MM/DD)·금액·필요충전수·충전잔액을 출력하라. 필요충전수는 금액/10000의 올림, 충전잔액은 충전수×10000-금액이다. 충전잔액 내림차순·날짜 오름차순·payment_id 순으로 정렬하고 상위 5건만 출력하라.

🎯 기대 결과 · 5행

모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT payment_id AS 결제ID, DATE_FORMAT(pay_date, '%Y/%m/%d') AS 결제일,
       amount AS 금액, CEIL(amount / 10000.0) AS 필요충전수,
       CEIL(amount / 10000.0) * 10000 - amount AS 충전잔액
FROM payment
WHERE pay_date >= '2024-01-01' AND pay_date < '2024-04-01' AND amount >= 20000
ORDER BY 충전잔액 DESC, pay_date, payment_id
LIMIT 5;

기간 필터를 먼저 적용하고, 충전잔액으로 정렬한 뒤 LIMIT을 적용한다.

Q9. 같은 결제월·금액 조합 제거 고난도

payment에서 금액이 20,000원 이상인 결제만 대상으로 결제월(YYYY-MM)·금액 조합을 중복 없이 출력하라. 같은 월에 같은 금액으로 여러 번 결제해도 한 행이다. 월 오름차순·금액 내림차순으로 정렬하라.

Q10. 환급 대상 필터와 두 번째 페이지 최상

payment에서 2024년 2~4월이고 금액이 20,000~50,000원인 결제를 골라라. 환급액은 40,000원 이상이면 금액의 12%, 나머지는 7%로 계산하고 내림한다. 결제ID·결제월(YYYY-MM)·금액·환급액을 출력하라. 환급액 내림차순·날짜 오름차순·payment_id 순으로 정렬한 목록에서 앞 2건을 건너뛰고 다음 3건만 출력하라.

모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT payment_id AS 결제ID, DATE_FORMAT(pay_date, '%Y-%m') AS 결제월,
       amount AS 금액, FLOOR(amount * IF(amount >= 40000, 0.12, 0.07)) AS 환급액

  AND amount BETWEEN 20000 AND 50000

SELECT char_name AS 캐릭터, combat_power AS 전투력,
       ABS(combat_power - 160000) AS 목표차이,
       IF(combat_power >= 160000, '달성', '미달') AS 판정,
       CASE WHEN combat_power >= 160000 THEN 0
            ELSE CEIL((160000 - combat_power) / 10000.0) END AS 보강단계
FROM character_tb
WHERE job_id IN (10, 11, 12) AND combat_power >= 100000
ORDER BY 목표차이, combat_power DESC, char_id
LIMIT 4;

목표차이는 절댓값이지만 보강단계는 부족한 캐릭터에게만 적용한다.

Q12. 복합 우선순위로 안내문 만들기 최상

user에서 가입일이 2024-01-01 이전이며, 등급이 있거나 레벨이 70 이상인 유저를 골라라. 우선순위는 VVIP이면 1, 그 외 나이 NULL이면 2, 그 외 레벨 80 이상이면 3, 나머지는 4다. 닉네임·우선순위·안내문을 출력하라. 안내문은 '닉네임 / 등급 / 나이세 / 가입:YYYY.MM' 형식이며, 등급 NULL은 일반, 나이 NULL은 '나이미입력'으로 표시한다. 우선순위 오름차순·레벨 내림차순·user_id 순으로 정렬하고 상위 5명만 출력하라.

모범답안과 풀이 포인트 보기
MySQL · answer.sql
SELECT nickname AS 닉네임,
       CASE WHEN vip_grade = 'VVIP' THEN 1
            WHEN age IS NULL THEN 2
            WHEN level >= 80 THEN 3 ELSE 4 END AS 우선순위,
       CONCAT(nickname, ' / ', IFNULL(vip_grade, '일반'), ' / ',
              IF(age IS NULL, '나이미입력', CONCAT(CAST(age AS CHAR), '세')),
              ' / 가입:', DATE_FORMAT(join_date, '%Y.%m')) AS 안내문
FROM user
WHERE join_date < '2024-01-01' AND (vip_grade IS NOT NULL OR level >= 70)
ORDER BY 우선순위, level DESC, user_id
LIMIT 5;

분류 조건의 순서와 NULL이 CONCAT 전체에 미치는 영향을 점검한다.
