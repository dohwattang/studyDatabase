집계 GROUP BY

블록 1/2

데이터를 묶는다 — GROUP BY

1.GROUP BY
2.집계 함수

지금까지는 '행을 고르는' 일이었다. 이제 여러 행을 묶어 요약한다. "서버별 유저 수", "이번 달 총매출" 같은 운영 지표가 전부 집계다.

그룹화 — GROUP BY

같은 값을 가진 행들을 하나의 그룹으로 묶는다. 서버별로 묶으면 서버 수만큼 결과가 나온다.

MySQL · query.sql
-- 서버별 유저 수
SELECT server_id,
       COUNT(*) AS 유저수
FROM user
GROUP BY server_id;

⚠️ GROUP BY의 철칙

SELECT 절에는 GROUP BY에 쓴 컬럼과 집계 함수만 올 수 있다. 그룹으로 묶은 마당에 개별 nickname을 같이 뽑으려 하면 의미가 깨진다. 이걸 어기면 MySQL이 경고하거나 엉뚱한 값을 준다.

GROUP BY 절의 위치

MySQL · query.sql
SELECT 컬럼, 집계함수
FROM 테이블
WHERE 조건           -- 묶기 전 필터
GROUP BY 컬럼
ORDER BY ...;         -- 정렬은 맨 뒤

DISTINCT 와의 차이

중복 제거만 원하면 DISTINCT, 묶어서 계산까지 하려면 GROUP BY.

MySQL · query.sql
-- 둘 다 '서버 종류'를 보여주지만
SELECT DISTINCT server_id FROM user;          -- 단순 중복제거
SELECT server_id FROM user GROUP BY server_id; -- 그룹화(집계 가능)

💡 ORDER BY에 별칭 사용

집계 결과(별칭 '결제총액')로 정렬할 수 있다. 매출 랭킹, 인기 아이템 순위가 이렇게 만들어진다.

🎯 서버별 평균 레벨 구하기 표준
  1. 서버별로 유저 수와 평균 레벨을 구한다
  2. 평균 레벨은 반올림한다
  3. 평균 레벨 높은 순으로 정렬한다
💬 힌트: GROUP BY server_id + COUNT(*), ROUND(AVG(level))
🎯 이런 결과가 나와야 한다

모범답안 보기
answer.sql
SELECT server_id AS 서버,
       COUNT(*) AS 유저수,
       ROUND(AVG(level)) AS 평균레벨
FROM user
GROUP BY server_id
ORDER BY 평균레벨 DESC;

📝 연습문제 — GROUP BY·집계

한 문제에서 여러 집계를 한꺼번에 다룬다. SELECT에는 GROUP BY 컬럼과 집계함수만 온다는 철칙, WHERE는 묶기 전에 거른다는 순서를 기억하자. 이 주차에서는 한 테이블만 사용한다.

Q1기초 payment 전체를 한 번의 SELECT로 요약하라. 컬럼명과 순서는 결제건수, 총매출, 평균결제(반올림), 최고결제, 최저결제.

모범답안 보기
answer.sql
SELECT COUNT(*) AS 결제건수,

       MIN(amount) AS 최저결제

Q9도전 user를 레벨 구간(컬럼명 구간)으로 나눠라: 80 이상 '고렙', 50 이상 '중렙', 나머지 '저렙'. 구간별 유저수, 최고레벨, 최저레벨을 구하고 최고레벨 높은 순으로 정렬하라.
💬 힌트: CASE로 만든 별칭(구간)을 GROUP BY에 그대로 쓸 수 있다.
🎯 이런 결과가 나와야 한다

answer.sql
SELECT CASE WHEN level >= 80 THEN '고렙'
            WHEN level >= 50 THEN '중렙'
            ELSE '저렙' END AS 구간,

FROM user
GROUP BY 구간
ORDER BY 최고레벨 DESC;

Q13도전 월별 결제 리포트. payment를 월별('2024-01' 형태, 컬럼명 월)로 묶어 건수, 매출, 고액건수, 고액매출을 구하라. 고액 = 20000원 이상. 월 순서대로.
💬 힌트: 조건에 맞으면 1(또는 금액), 아니면 0을 만들어 SUM하면 '조건부 합계'가 된다.
🎯 이런 결과가 나와야 한다
월건수매출고액건수고액매출

모범답안 보기
answer.sql
SELECT DATE_FORMAT(pay_date, '%Y-%m') AS 월,
       COUNT(*) AS 건수,
       SUM(amount) AS 매출,
       SUM(IF(amount >= 20000, 1, 0)) AS 고액건수,
       SUM(IF(amount >= 20000, amount, 0)) AS 고액매출
FROM payment
GROUP BY DATE_FORMAT(pay_date, '%Y-%m')
ORDER BY 월;
