조건 조회 WHERE

블록 1/2

조건으로 골라내기 — WHERE

1.비교·LIKE
2.IN·BETWEEN·논리

전체가 아니라 조건에 맞는 행만 골라낸다. WHERE는 운영 데이터에서 "내가 찾는 그 유저/그 결제"를 집어내는 핵심 도구다.

WHERE의 위치와 구조

MySQL · query.sql
SELECT 컬럼
FROM 테이블
WHERE 조건;        -- 조건이 참(TRUE)인 행만 조회

조건은 컬럼 · 연산자 · 값으로 이뤄진다. 예: level >= 80

비교 연산자

연산자의미예
=같다server_id = 1
<> 또는 !=다르다vip_grade <> 'VIP'
> >=크다/이상level >= 80
< <=작다/이하age < 20
MySQL · query.sql
-- 레벨 80 이상 고렙 유저
SELECT nickname, level
FROM user
WHERE level >= 80;

LIKE — 문자열 패턴 검색

%는 '아무 문자나 0글자 이상'을 뜻한다. 닉네임·아이디 검색에 필수.

패턴의미
'김%'김으로 시작
'%검'검으로 끝
'%의%'중간에 '의'가 들어감
MySQL · query.sql
-- 닉네임에 '의'가 들어간 유저
SELECT nickname
FROM user
WHERE nickname LIKE '%의%';

💡 게임 운영 활용

욕설·불건전 닉네임 필터링, 특정 이벤트 아이템명 검색 등에 LIKE가 쓰인다. item_name LIKE '%포션%' 으로 모든 포션류를 한 번에 찾는다.

블록 2/2

여러 값·범위·복합 조건

1.비교·LIKE
2.IN·BETWEEN·논리

여러 값·범위·복합 조건을 다룬다. 실무 쿼리는 조건이 여러 개 겹치는 게 보통이다.

IN — 여러 값 중 하나

"1번 또는 3번 서버"처럼 여러 값을 깔끔하게 처리한다.

MySQL · query.sql
-- 아래 두 쿼리는 같은 결과
SELECT nickname, server_id FROM user
WHERE server_id = 1 OR server_id = 3;

SELECT nickname, server_id FROM user
WHERE server_id IN (1, 3);

BETWEEN — 범위

"레벨 40 이상 80 이하"를 한 번에. 경계값을 포함한다.

MySQL · query.sql
SELECT nickname, level FROM user
WHERE level BETWEEN 40 AND 80
ORDER BY level;

📌 BETWEEN = AND 두 개

level BETWEEN 40 AND 80 은 level >= 40 AND level <= 80 과 완전히 같다. 더 짧아서 즐겨 쓴다.

논리 연산자 — AND · OR · NOT

여러 조건을 묶는다. AND는 둘 다 참, OR는 하나라도 참.

MySQL · query.sql
-- 1번 서버이면서 레벨 70 이상
SELECT nickname FROM user
WHERE server_id = 1 AND level >= 70;
nickname
검은기사
화살의달인
⚠️ AND/OR 섞을 땐 괄호

AND가 OR보다 먼저 계산된다. 의도대로 묶으려면 괄호를 쓴다.
WHERE (server_id=1 OR server_id=2) AND level>=80

🎯 이벤트 대상 유저 추출 도전

다음 조건을 모두 만족하는 유저의 닉네임·레벨·서버를 뽑아라. (고렙 이벤트 대상자 선정)

  1. 1번 또는 2번 서버 소속
  2. 레벨 80 이상
  3. 레벨 높은 순 정렬
💬 힌트: IN 으로 서버 조건, AND 로 레벨 조건을 묶는다
모범답안 보기
answer.sql
SELECT nickname AS 닉네임, level AS 레벨, server_id AS 서버
FROM user
WHERE server_id IN (1, 2)
  AND level >= 80
ORDER BY level DESC;
