데이터베이스(DB)란

데이터를 체계적으로 저장하고 꺼내쓰기 위한 창고다. 엑셀과 비슷해 보이지만, 수백만 건을 다루고 여러 사람이 동시에 접근해도 안전하다는 점이 다르다. 게임은 유저·아이템·결제가 끊임없이 쌓이므로 DB 없이는 운영이 불가능하다.

DBMS와 MySQL

DB를 관리하는 소프트웨어를 DBMS라 한다. 그중 MySQL은 세계에서 가장 많이 쓰이는 오픈소스 DBMS로, 게임 서버 백엔드에서도 표준처럼 쓰인다. 이 수업은 MySQL 8.x를 기준으로 한다.

⚠️ 설치 — 빠른 안내

다음 두 가지만 설치하면 된다. 자세한 설치는 첫 시간에 함께 진행한다.

  1. MySQL Community Server 8.x — 실제 DB 엔진
  2. MySQL Workbench — 쿼리를 작성·실행하는 GUI 도구

설치 후 Workbench에서 localhost 연결을 만들고, 비밀번호로 접속되면 준비 끝이다. (Mac은 DBeaver를 써도 무방)

SQL 문장의 3가지 약속

  • 대소문자를 구분하지 않는다. SELECT = select (단, 가독성을 위해 키워드는 대문자로 쓰는 게 관례)
  • 한 문장의 끝은 반드시 세미콜론 ;
  • 문자열은 작은따옴표 '아스가르드' 로 감싼다

이 수업의 모든 실습은 아래 게임 운영 데이터베이스(game_db) 하나로 진행한다. 넥슨 같은 게임사의 운영팀이 실제로 다루는 데이터(유저·캐릭터·결제·아이템)를 교육용으로 단순화한 것이다. 매주 같은 DB를 쓰므로, 한 번 만들어두면 학기 내내 재사용한다.

테이블의미주요 컬럼

📌 왜 게임 데이터로 배우나?

SQL은 '데이터를 질문하는 언어'다. 게임 운영자가 매일 던지는 질문 — "레벨 80 이상 유저 누구?", "이번 달 서버별 매출은?", "결제 한 번도 안 한 유저는?" — 이 모든 게 SQL 한 줄이다. 추상적인 예제보다 여러분이 만들 게임의 데이터로 배우는 게 빠르다.

1단계 — 데이터베이스(스키마) 만들기

테이블을 담을 공간을 먼저 만든다. 게임 DB 이름은 game_db로 한다.

MySQL · query.sql
-- 데이터베이스 생성
CREATE DATABASE IF NOT EXISTS game_db;

-- 앞으로 이 DB를 사용하겠다고 선언
USE game_db;
💡 IF NOT EXISTS

이미 같은 이름의 DB가 있으면 에러가 난다. IF NOT EXISTS를 붙이면 있으면 그냥 넘어가므로, 실습을 여러 번 돌려도 안전하다.

2단계 — 테이블 만들기 (CREATE TABLE)

테이블은 컬럼(열)의 설계도다. 각 컬럼마다 이름 + 데이터 타입을 정한다. 가장 단순한 job(직업) 테이블부터 만들어보자.

MySQL · query.sql
CREATE TABLE job (
    job_id    INT          NOT NULL,   -- 직업 번호 (숫자)
    job_name  VARCHAR(20)  NOT NULL,   -- 직업 이름 (최대 20글자)
    job_type  VARCHAR(10)  NOT NULL    -- 직업 분류
);

대표 데이터 타입

타입쓰임예
INT정수level, price, age
VARCHAR(n)가변 문자열(최대 n글자)nickname, item_name
DATE날짜(YYYY-MM-DD)join_date, pay_date
DECIMAL(m,n)소수(정밀)환율, 정확한 금액
📌 NULL vs NOT NULL

NULL은 '값이 없음'을 뜻한다. 유저의 나이처럼 입력이 선택인 컬럼은 NULL을 허용하고, 닉네임·레벨처럼 반드시 있어야 하는 컬럼은 NOT NULL로 막는다. 다음 주에 자세히 다룬다.

🎯 job 테이블을 만들고 확인하기 기초
  1. 위 CREATE 문으로 job 테이블을 생성한다
  2. 제대로 만들어졌는지 구조를 확인한다
💬 힌트: 테이블 구조 확인은 DESC 테이블명;
모범답안 보기
answer.sql
CREATE TABLE job (
    job_id    INT          NOT NULL,
    job_name  VARCHAR(20)  NOT NULL,
    job_type  VARCHAR(10)  NOT NULL
);

-- 테이블 구조 확인
DESC job;
🚫 테이블 삭제는 신중히

DROP TABLE job; 한 줄이면 테이블과 안의 데이터가 전부 사라진다. 되돌릴 수 없다. 실습 중 다시 만들고 싶을 때만 사용한다.

1주차 치트시트

CREATE DATABASE 이름;데이터베이스 생성
USE 이름;해당 DB 사용 선언
CREATE TABLE 명 ( 컬럼 타입 ... );테이블 생성
DESC 테이블;테이블 구조 확인
DROP TABLE 테이블;테이블 삭제(주의)
INT / VARCHAR(n) / DATE대표 데이터 타입
