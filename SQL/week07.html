블록 1/2

함수 누적 실습

1.함수 누적 실습
2.WHERE·정렬 복합
📌 이번 주는 '실습 주간'

새 문법은 없다. 3~6주에 배운 SELECT·WHERE·함수를 한꺼번에 섞어 쓰는 연습이다. 운영 현장의 쿼리는 항상 여러 기능이 겹친다. 중간고사 직전 총정리이기도 하다.

난이도를 단계적으로 올린다. 막히면 해당 주차 치트시트로 돌아가 확인하자.

🎯 아이템 가격표 정리 기초

무기 카테고리 아이템의 이름과 가격을, 가격 높은 순으로 출력하라.

🎯 기대 결과 · 3행
아이템가격
엑스칼리버29900
암흑단검27900
미스릴활24900
모범답안 보기
answer.sql
SELECT item_name AS 아이템, price AS 가격
FROM item
WHERE category = '무기'
ORDER BY price DESC, item_id;
🎯 포션류 찾기 + 할인가 표준

이름에 '포션'이 들어간 아이템의 이름·정가·20%할인가를 구하라. 할인가는 반올림.

💬 힌트: LIKE '%포션%' + ROUND(price*0.8)
🎯 기대 결과 · 2행
아이템정가할인가
체력포션x10900720
마나포션x10900720
모범답안 보기
answer.sql
SELECT item_name AS 아이템,
       price AS 정가,
       ROUND(price * 0.8) AS 할인가
FROM item
WHERE item_name LIKE '%포션%'
ORDER BY item_id;
🎯 신규 유저 명단 (등급 채우기) 표준

2023년 이후 가입한 유저의 닉네임·가입일·VIP등급을 뽑되, 등급이 없으면 '일반'으로 표시하라.

💬 힌트: WHERE join_date >= '2023-01-01' + IFNULL
🎯 기대 결과 · 3행
닉네임가입일등급
백전노장2023-02-01VVIP
초보모험가2023-09-01일반
주말전사2024-03-01일반
모범답안 보기
answer.sql
SELECT nickname AS 닉네임,
       join_date AS 가입일,
       IFNULL(vip_grade, '일반') AS 등급
FROM user
WHERE join_date >= '2023-01-01'
ORDER BY join_date, user_id;
블록 2/2

복합 조건 리포트 만들기

1.함수 누적 실습
2.WHERE·정렬 복합

조건을 여러 개 겹치고, 함수로 가공하고, 정렬까지. 실전 리포트 수준의 쿼리를 완성한다.

🎯 이벤트 대상자 + 명패 도전

레벨 70 이상이면서 1·2번 서버 소속인 유저의 명패를 '불꽃마녀 [Lv.90]' 형태로 만들고, 레벨 높은 순으로 정렬하라.

💬 힌트: CONCAT + WHERE(AND, IN) + ORDER BY를 한 쿼리에
🎯 기대 결과 · 3행
명패
불꽃마녀 [Lv.90]
검은기사 [Lv.85]
화살의달인 [Lv.72]
모범답안 보기
answer.sql
SELECT CONCAT(nickname, ' [Lv.', level, ']') AS 명패
FROM user
WHERE level >= 70
  AND server_id IN (1, 2)
ORDER BY level DESC, user_id;
🎯 유저 레벨 구간 리포트 도전

전체 유저를 레벨 구간으로 분류하고(90+만렙급/70+고렙/40+중렙/그외 초보), 닉네임·레벨·구간·나이를 출력하라. 단 나이가 없으면 '미입력'으로 표시하고, 레벨 높은 순 정렬.

💬 힌트: CASE + IFNULL을 한 SELECT에 함께 쓴다
🎯 기대 결과 · 8행
닉네임레벨구간나이
백전노장99만렙급35
불꽃마녀90만렙급31
검은기사85고렙27
그림자칼날78고렙24
화살의달인72고렙미입력
치유의손64중렙미입력
주말전사40중렙미입력
초보모험가15초보19
모범답안 보기
answer.sql
SELECT nickname AS 닉네임,
       level AS 레벨,
       CASE WHEN level >= 90 THEN '만렙급'
            WHEN level >= 70 THEN '고렙'
            WHEN level >= 40 THEN '중렙'
            ELSE '초보'
       END AS 구간,
       IFNULL(age, '미입력') AS 나이
FROM user
ORDER BY level DESC, user_id;

💡 중간고사 대비 체크리스트
  • SELECT 컬럼 고르기 / 별칭 AS
  • WHERE 비교·LIKE·IN·BETWEEN·AND/OR
  • ORDER BY (다중 정렬) / LIMIT / DISTINCT
  • 숫자함수 ROUND·MOD / 문자함수 CONCAT·SUBSTRING·REPLACE
  • 날짜함수 YEAR·DATE_FORMAT / 형변환 CAST
  • IFNULL · IF · CASE

이 여섯 줄을 빈 쿼리에서 막힘없이 쓸 수 있으면 중간고사 준비 완료다.
