숫자형·문자형 함수

블록 1/2

숫자를 다루는 함수

1.숫자형 함수
2.문자형 함수

함수는 값을 넣으면 가공된 값을 돌려주는 기계다(y=f(x)). 가격을 반올림하고, 닉네임 길이를 재는 등 데이터를 다듬을 때 쓴다.

숫자형 함수

함수기능예 → 결과
ABS(x)절댓값ABS(-7) → 7
ROUND(x, n)반올림(소수 n자리)ROUND(29900/1000) → 30
CEIL(x)올림CEIL(4.1) → 5
FLOOR(x)내림FLOOR(4.9) → 4
MOD(a, b)나머지MOD(10,3) → 1
POWER(a, b)거듭제곱POWER(2,10) → 1024
MySQL · query.sql
-- 아이템 가격을 천원 단위로 반올림
SELECT item_name,
       price,
       ROUND(price / 1000) AS 천원단위
FROM item;

엑스칼리버2990030

💡 게임 밸런싱과 함수

데미지 계산, 확률 보정, 가격 환산 등 게임 수치는 결국 숫자 연산이다. ROUND·FLOOR는 재화 표시(소수점 버리기), MOD는 주기 이벤트(N일마다) 판정에 자주 쓰인다.

수식 연산자

SELECT 절에서 바로 계산도 된다. + - * / %

MySQL · query.sql
-- 아이템에 10% 할인가 계산
SELECT item_name,
       price AS 정가,
       ROUND(price * 0.9) AS 할인가
FROM item
WHERE category = '무기';

블록 2/2

문자열을 다루는 함수

1.숫자형 함수
2.문자형 함수

문자열을 자르고, 잇고, 바꾼다. 닉네임·아이디·로그 텍스트를 다루는 모든 곳에 쓰인다.

문자형 함수

함수기능예 → 결과
LENGTH(s) / CHAR_LENGTH(s)길이(바이트/글자수)CHAR_LENGTH('검은기사') → 4
CONCAT(a,b,..)문자열 잇기CONCAT(nickname,'님')
SUBSTRING(s,시작,길이)일부 잘라내기SUBSTRING(login_id,1,3)
REPLACE(s,찾기,바꾸기)치환REPLACE('a,b',',','/')
UPPER / LOWER대/소문자UPPER('abc') → ABC
LPAD(s,길이,채움)왼쪽 채우기LPAD('7',3,'0') → 007
TRIM(s)앞뒤 공백 제거TRIM(' hi ') → hi
⚠️ MySQL 한글과 LENGTH

MySQL에서 LENGTH는 바이트 수라 한글 1글자가 3으로 센다. 글자 수를 세려면 CHAR_LENGTH를 써야 한다.

CONCAT — 문자열 잇기

MySQL · query.sql
-- 닉네임 뒤에 '님' 붙이기
SELECT CONCAT(nickname, '님') AS 인사말
FROM user
LIMIT 3;

화살의달인님

SUBSTRING — 잘라내기

MySQL · query.sql
-- 로그인 아이디 앞 3글자만
SELECT login_id,
       SUBSTRING(login_id, 1, 3) AS 앞3글자
FROM user
LIMIT 3;
login_id앞3글자

arrowmasterarr
firemagefir

REPLACE — 치환

로그 데이터의 구분자를 바꾸거나, 금지어를 가릴 때 쓴다.

MySQL · query.sql
-- 산토끼 토끼야 → 산거북이 거북이야
SELECT REPLACE('산토끼 토끼야', '토끼', '거북이') AS 결과;
결과
산거북이 거북이야
🎯 유저 명패 만들기 표준
  1. 유저의 닉네임과 레벨로 '검은기사 (Lv.85)' 형태의 명패를 만든다
  2. 컬럼명은 '명패'로 한다
💬 힌트: CONCAT 안에 여러 조각을 콤마로 넣는다. 숫자 level도 그대로 이어진다
모범답안 보기
answer.sql
SELECT CONCAT(nickname, ' (Lv.', level, ')') AS 명패
FROM user
ORDER BY level DESC;

Q15도전 무기 아이템에 15% 할인가를 반올림해 '아이템','정가','할인가'로 조회하라. (할인가 낮은 순)
🎯 이런 결과가 나와야 한다
아이템정가할인가
미스릴활2490021165.0
암흑단검2790023715.0
엑스칼리버2990025415.0
모범답안 보기
answer.sql
SELECT item_name AS 아이템,
       price AS 정가,
       ROUND(price*0.85) AS 할인가
FROM item
WHERE category = '무기'
ORDER BY 할인가;
